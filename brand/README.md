# QA Inspector · Focus

- `qa-inspector-icon.svg` — основна кольорова іконка.
- `qa-inspector-mark.svg` — знак без фону для світлих поверхонь.
- `qa-inspector-mono.svg` — одноколірний знак, використовує currentColor.
- `qa-inspector-wordmark.svg` — горизонтальна композиція з назвою, літери у векторних контурах.

Сітка 256 × 256; однакові кути рамки, симетричні поля, заокруглені завершення. Жодних растрових зображень, зовнішніх ресурсів чи залежностей від шрифтів. У Figma імпортуйте SVG; за потреби застосуйте Outline stroke. Для портфоліо використовуйте SVG без растрування. Для браузера існує окремий набір малих PNG у extension/icons.

Кольори: фіолетовий #5148E5, м’ятний #65F6D2, білий #FFFFFF. У прозорій версії галочка темніша (#168A73), щоб добре читатися на світлому фоні.
