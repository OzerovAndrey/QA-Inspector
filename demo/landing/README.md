# Luma · контрольний лендінг

Вигаданий сервіс для нотаток. Жодних серверів, форм відправки чи зовнішніх шрифтів.

## Як перевіряти

1. Відкрийте index.html або опубліковану сторінку у Chrome.
2. Відкрийте QA Inspector → завантажте design-system.json кнопкою «Завантажити JSON / ZIP». Це конфігурація з явними правилами компонентів, а не просто словник токенів.
3. Виберіть тему luma/light (або luma/dark відповідно до теми сторінки). Після зміни теми перевірте тему еталона в панелі.
4. У вкладці «Сторінка» натисніть «Сканувати сторінку».
5. Очікуйте **17 елементів: 8 відповідають, 8 з відхиленнями, 1 не порівняно; 49 перевірок властивостей**. Кожен помилковий елемент має рівно одну невідповідність.
6. Клікніть кожен конфлікт: підсвітка має вказувати на відповідний елемент. Перевірте копіювання коду та файл для фронтенду.
7. Натисніть «Прибрати помилки» на сторінці й повторіть скан: **16 відповідають, 0 відхилень, 1 не порівняно**.
8. Повторіть у Dark. Результати мають бути такими самими.

Для file:// увімкніть доступ до URL файлів у деталях розширення. Кнопки сторінки не змінюють JSON. Після зміни стану повторіть скан.

## Контрольний список помилок

| Елемент | Властивість | На сайті | Еталон |
| --- | --- | --- | --- |
| heading-bad | font-size | 48px | 56px |
| body-bad | color | #d13f52 | Light #253c34 / Dark #e5eee6 |
| primary-bad | padding-left | 32px | 20px |
| secondary-bad | border-top-left-radius | 24px | 10px |
| card-bad | padding-top | 44px | 28px |
| badge-bad | font-weight | 400 | 700 |
| input-bad | height | 58px | 46px |
| stack-bad | gap | 30px | 16px |

gradient має фон-градієнт: backgroundColor — **Not comparable**, а не Fail/Pass. Цей випадок залишається і після прибирання помилок.

Правила прив'язані до data-qa. Навігація, декоративні елементи та панель лабораторії не входять у ці 17 контрольних компонентів. Перевірка без JSON збирає ширший набір елементів і не має наведених очікуваних підсумків.

JSON написаний як окремий фіктивний еталон дизайнера; CSS реалізує його незалежно. Розширення не генерує еталон зі сторінки. Тест tests/landing-smoke.cjs вимірює справжній computed style і перевіряє точний список конфліктів у двох темах, чистий стан та мобільну ширину.
