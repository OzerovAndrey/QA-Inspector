# Робота з iPhone

GitHub: https://github.com/OzerovAndrey/QA-Inspector

## Через підключений комп'ютер

1. На Mac відкрийте Codex і проєкт qa-inspector.
2. У Settings → Connections знайдіть Control this Mac or PC та пройдіть налаштування підключення.
3. На iPhone відкрийте ChatGPT → Codex (у деяких версіях Remote), увійдіть у той самий обліковий запис і робочий простір та підключіться за QR-кодом.
4. Залишайте Mac увімкненим, підключеним до мережі та без сну під час роботи.

## Через Cloud

Спершу в Codex на комп'ютері або у вебверсії створіть Cloud environment для репозиторію OzerovAndrey/QA-Inspector, перевірте налаштування та опублікуйте середовище. Далі оберіть його в Codex на iPhone. Для перевірок достатньо Node.js 22 і npm ci, команда тестів — npm test.

Доступність і назви пунктів залежать від версії застосунку та робочого простору. Створення репозиторію саме по собі не підключає телефон і не налаштовує Cloud.

З iPhone можна ставити завдання, перевіряти зміни та працювати з кодом через Codex. Саме Chrome-розширення встановлюється і перевіряється у Chrome на комп'ютері.

Офіційні інструкції: https://learn.chatgpt.com/docs/mobile та https://learn.chatgpt.com/docs/environments/modes
