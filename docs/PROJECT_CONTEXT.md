# Контекст проєкту · v0.7

QA Inspector — локальний Chrome Extension Manifest V3 для інспекції CSS та перевірки відповідності дизайн-системі.

## Поточна поведінка

- Компонент: наведення показує computed CSS, клік фіксує результат; Esc завершує вибір, стрілки вгору/вниз переходять між батьком/нащадком.
- Сторінка: збір властивостей знайдених елементів.
- Сайт: обхід сторінок у межах дозволеного сайту з прогресом, скасуванням і частковим звітом.
- Без еталона доступне витягування даних. Імпорт JSON/ZIP вмикає необов'язкове порівняння.
- Кожна вкладка має власні результати та експорт JSON/Markdown.

## Де що лежить

extension/ — готове розширення, panel.* — інтерфейс, picker.js — вибір елементів, scanner.js — зчитування, scan-core.js — оцінювання, import-system.js — імпорт, site-runner.js — обхід.

demo/ — локальна демосторінка; designer/ — приклади; fixtures/atlas/ — тестові джерела з походженням у PROVENANCE.md. Atlas не є обов'язковим сайтом продукту.

## Перевірки

npm test — тести нормалізації, імпорту, порівняння та обходу.

npm run test:browser — інтерфейс і CSS у браузері з імітацією API Chrome.

npm run test:extension — реальне MV3 розширення на локальному тестовому сайті, тимчасовий профіль. Потрібен Chrome/Chromium з підтримкою Extensions.loadUnpacked через CDP.

Для браузерних тестів: npm ci, потім npx playwright install chromium. На macOS використовується встановлений Google Chrome; QA_CHROME_PATH задає інший виконуваний файл. QA_PLAYWRIGHT дозволяє вказати зовнішню інсталяцію Playwright.

## Подальша робота

Покращувати зрозумілість даних та еталонів, сумісність імпорту і точність зіставлення. Не видавати збіг зі словником токенів за підтвердження правильності конкретного компонента. Усі нові можливості перевіряти на нейтральних прикладах.

## Оновлення інтерфейсу · 26 жовтня 2026

Три візуальні області: темна шапка з логотипом, біла робоча картка й окрема картка результатів. Кнопки мають іконки відповідного режиму. Активний пікер має зелений стан кнопки й курсор-хрестик на сайті; завершення прибирає курсор. Іконки Chrome: extension/icons/ (16/32/48/128 PNG), джерело — logo.svg.

## Стан сторінки

Еталон і результати прив’язані до вкладки та URL. Перехід на іншу сторінку, перезавантаження або перемикання на іншу вебвкладку скидає попередню перевірку. «Скинути все» також зупиняє пікер/обхід і видаляє еталон та результати з локального сховища інспектора.

Еталони тепер зберігаються окремо за origin сайту (для file:// — за папкою). Перехід очищає лише результати поточної сторінки; повернення відновлює JSON, режим порівняння й тему. «Скинути все» видаляє всі збережені еталони. Дозвіл tabs використовується для визначення адреси активного сайту.
