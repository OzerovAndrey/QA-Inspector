# Бічна панель · компактний UI

## Що змінилося

- Хедер із логотипом, статусом Figma та меню. Підключення/відключення перенесено в поповер статусу.
- «Скинути все» в меню; перед виконанням — діалог підтвердження. Токен, як раніше, не видаляється скиданням.
- Доступ і допомога в меню. Контекстний банер з’являється лише без доступу; захищені сторінки Chrome пояснено окремо.
- Таби режимів і один primary CTA зверху. Старі заголовки/описи режимів приховані; інструкції зібрані в empty state та підказці активного пікера.
- Експорт прихований без даних. Split-кнопка делегує копіювання старому обробнику, JSON і Markdown — старим завантаженням.
- Порівняння завжди розкрите внизу, із логотипом Figma біля заголовка. Немає вкладеної картки, сегментів Figma/JSON, нумерації та великого блоку підключення.
- Вставка URL застосовує точний шар за наявним selection link. Посилання на canvas, де потрібен вибір, відкриває наявний список шарів.
- JSON/ZIP можна перетягнути навіть на згорнуту секцію або вибрати кнопкою без акаунта Figma. JSON-текст у спільному полі передається тому самому імпортеру як файл.
- Рядок застосованого макета з назвою, заміною й видаленням. Перемикач порівняння, вибір шару, перевірка брейкпоінта, оновлення та теми JSON збережені в додаткових секціях. Мініатюра не додається: чинний імпортер її не отримує.
- Фіолетовий — primary/active, зелений — лише успіх. Відступи 16/20px, типографіка від 12px, кнопки 40/32px, клавіатурний focus-ring.
- Поточний проєкт не мав темної теми; додаткової теми ця зміна не запроваджує.

## Межі змін у логіці

`panel-shell.js` — UI-адаптер: переміщує існуючі елементи з їхніми ID та обробниками, показує стани, перевіряє доступ read-only, передає paste/drop існуючим імпортерам та підтверджує reset.

У `figma-ui.js` мінімальна UI-обгортка `autoApply`: після чинного завантаження викликається той самий `makeFigmaSystem`/`useSystem` для точного шару URL. Додано UI-події стану підключення; fetch/API, токени й збереження не перероблені.

У `panel.js` підключено адаптер, передано read-only getter поточного стану та подію оновлення UI. Сканер, пікер, правила порівняння, бізнес-експорт і схеми storage не змінені. Адаптації позначено коментарями.

## Ручна перевірка

- [ ] 370px: немає горизонтального скролу; тексти від 12px, primary 40px, secondary 32px.
- [ ] Без токена: `○ Figma`; клік → «Підключити Figma», поле токена й інструкція.
- [ ] Невірний токен: помилка поля, інструкція; після закриття доступне редагування токена.
- [ ] Збереження токена: `● Figma`, секція макета відкривається; відключення в поповері видаляє токен, не макет.
- [ ] API 401/403: показано помилку підключення та пояснення; після успішного запиту статус відновлюється.
- [ ] Порожній макет: секція відкрита, видно логотип Figma та підключення або поле посилання.
- [ ] Валідне selection-посилання: стан валідації → назва застосованого шару без додаткової кнопки.
- [ ] Невалідне посилання: inline-помилка; попередній макет не видаляється.
- [ ] Canvas із кількома шарами: можна обрати шар і застосувати через додатковий список.
- [ ] Drop JSON/ZIP, кнопка вибору файлу та JSON paste: той самий імпорт, помилки й збереження попереднього макета.
- [ ] «Прибрати», «Замінити», перемикач порівняння, оновлення, брейкпоінт, теми JSON доступні.
- [ ] Пікер неактивний: empty state містить єдину головну інструкцію.
- [ ] Пікер активний: «Клік — зафіксувати · Esc — скасувати»; Esc завершує режим.
- [ ] Елемент обрано: властивості, іконки, підсвітка, HSL і конфлікти працюють як раніше.
- [ ] Немає результатів: експорт прихований. Є результати: копіювання, JSON, Markdown через split-кнопку.
- [ ] Компонент/Сторінка/Сайт зберігають незалежні результати, перемикаються мишкою та клавіатурою.
- [ ] Без доступу: контекстний банер над CTA; після надання доступу він зникає. За наявності доступу пункт лишається тільки в меню.
- [ ] `chrome://` та недоступні file:// мають зрозуміле пояснення; немає хибного повідомлення про готовність.
- [ ] «Скинути все»: скасування не змінює даних; підтвердження запускає попередню функцію очищення.
- [ ] Tab/Shift+Tab, Enter/Space, Escape у поповерах і діалозі; фокус видно.
- [ ] Перезавантаження панелі та переходи між сайтами відновлюють належний макет/результат.

## Автоматичні перевірки

`npm test`, `npm run test:browser`, `npm run test:extension`, `npm run test:figma`. Браузерні сценарії використовують тимчасові профілі та контрольовані сторінки/API; це не підтвердження точності зіставлення приватного живого макета з продом.
