Еталон дизайну

Порівняйте сайт із дизайном за JSON або ZIP.

Для чого потрібен еталон?

Попросіть дизайнера надати JSON із дизайн-токенами або правилами компонентів, щоб знайти відмінності у шрифтах, кольорах, розмірах і відступах сайту.

Підтримуються Tokens Studio, DTCG та конфігурація QA Inspector. Токени визначають допустимі значення, а правила компонентів — вимоги до конкретних елементів.

Звичайний JSON зі звітом, зображення, PDF та файли Figma не є еталоном. Імпорт також підтримує ZIP із JSON-файлами.

Без еталона можна переглядати властивості сайту без оцінки відповідності. Файл зберігається лише у вашому браузері.

Доступ до сайту й допомога

Без еталона інспектор показує шрифти, кольори, розміри та відступи сайту. З еталоном — знаходить відмінності від правил дизайну.

Для локальних файлів увімкніть «Дозволити доступ до URL файлів» у деталях розширення. chrome:// та інші захищені сторінки Chrome недоступні.

Пікер: клік фіксує; ↑/↓ змінюють рівень; Alt вибирає батьківський блок; Esc завершує. Приховані елементи, iframe й Shadow DOM не скануються. Обхід сайту використовує фонові вкладки та переходить за посиланнями в межах сайту. Типовий ліміт — 20 адрес.

Локально. Без сервера та прив’язки до проєкту.
