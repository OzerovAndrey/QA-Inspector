## Що показано

Реальні знімки локально запущеного MV3 розширення: імпорт JSON, інспекція елемента, наведення на відступ, список конфліктів, підсвічування на сторінці, експорт звіту й повторна перевірка.

Контрольний лендінг Luma: 17 елементів, 49 перевірок властивостей, 8 навмисних конфліктів. Після прибирання помилок — 0 конфліктів. Один градієнтний фон не порівнюється. Це результати тестового прикладу, не оцінка повноти перевірки довільного сайту.

Ролик змонтовано з реальних кадрів інтерфейсу та пояснювальних екранів; це відеопрезентація, а не безперервний запис робочого столу. Економію часу не вимірювали: фінальний екран пропонує пілот для її оцінювання.
